# 研究概要 — 視覚マーカを用いたロボットアームの位置認識・制御

最終更新: 2026-07-21

---

## 1. 研究テーマ

**Intel RealSense 深度カメラで検出した ArUco マーカの位置情報をもとに、myCobot 320 ロボットアームを目標位置へ制御する** ことを目指す研究。

カメラ画像から「どこに」「どのマーカ（物体）があるか」を認識し、その3次元位置をロボットアームの座標系に変換して動作させる、いわゆる **ビジュアルサーボ / ハンドアイ制御** の基盤構築を進めている。

現時点では以下の3つの要素技術を **個別に動作確認する段階** にあり、最終的にこれらを1つのパイプラインへ統合する。

```
[RealSense カメラ] --画像/深度--> [ArUco マーカ検出] --3D座標--> [座標変換] --> [myCobot 320 制御]
```

---

## 2. 使用機材・環境

| 区分 | 内容 |
| --- | --- |
| ロボットアーム | myCobot 320 (6自由度) / 制御は Raspberry Pi 上（`PI_PORT`, `/dev/ttyAMA0`, 115200 bps） |
| 制御ライブラリ | `pymycobot`（`MyCobot320` / `MyCobot`） |
| 深度カメラ | Intel RealSense（Depth + RGB, 640×480 @30fps） |
| 画像処理 | OpenCV `cv2.aruco`（辞書 `DICT_4X4_50`） |
| 開発言語 | Python 3.12 / 3.13 |

## 3. 要素技術と実装状況

### 3-1. ロボットアーム制御（`hand.py`, `setting.py`）

- `setting.py` … 接続確認用。バージョン・関節角度・座標・電源状態を取得する疎通テスト。
- `hand.py` … 制御本体。
  - 電源 ON → 初期姿勢 `[0,0,0,0,0,0]` へ移動
  - 現在の手先座標 (X, Y, Z) を取得
  - ユーザが入力した移動量（cm）を mm に変換し、目標座標を計算
  - 姿勢 (Rx, Ry, Rz) は維持したまま `send_coords()` で移動
  - **安全範囲チェック**（X:10〜330, Y:-150〜250, Z:50〜500 mm）を実装済み（現在はコメントアウトで無効化中）

> ✅ 手先座標ベースでの相対移動が動作。安全範囲の実機調整が今後の課題。

### 3-2. ArUco マーカの生成・認識（`ArMarker/script/`）

- `arMarkerGenerator.py` … `DICT_4X4_50` から ID 0〜8 のマーカ画像（150px）を生成し、3×3 に結合した一覧画像も出力（`ar0.png`〜`ar9.png`）。
- `arMarkerRecognizer.py` … 生成済み画像を読み込み、検出結果を描画して保存（`ar_detection0.png`〜）。

> ✅ 静止画レベルでのマーカ生成・検出のパイプラインが完成。

### 3-3. RealSense × ArUco リアルタイム検出（`ArucoDetection.py`, `Identify_marker.py`）

- RealSense のカラーストリームを取得し、フレームごとに ArUco を検出。
- 検出したマーカに枠・ID・中心点を描画し、中心座標 (center_x, center_y) を算出。
- `q` / `ESC` キーで終了。

> ✅ カメラ映像からのリアルタイム ID 検出と2D中心座標の取得まで動作。

### 3-4. RealSense 接続・深度取得テスト（`rstest*.py`, `rs_sensor.py` ほか）

- `numberOfCamera.py`, `rs_sensor.py`, `realsense.py`, `pipe.py` … デバイス台数・シリアル番号・センサ構成の確認。
- `rstest_official.py` … 深度フレーム中心の距離を連続表示する公式サンプル（タイムアウト10秒）。
- `rstest.py` … Depth + Color 両ストリームの有効化、デバイス情報表示、ウォームアップ後のフレーム取得。接続安定性の検証コード。

> ⚙️ Depth と Color の同時取得、接続安定性を検証中（デバッグ段階）。

## 5. 今後の課題（統合に向けて）

1. **深度情報とマーカ位置の対応付け**
   マーカ中心の2D座標 (u, v) に深度フレームの距離 D を組み合わせ、カメラ座標系の3D点 (X, Y, Z) を復元する。
2. **座標変換（キャリブレーション）**
   カメラ座標系 → ロボット座標系への変換行列（ハンドアイキャリブレーション）を求める。
3. **RealSense 接続の安定化**
   Depth + Color 同時取得時のタイムアウト・接続不良の解消（現在デバッグ中）。
4. **制御の自動化**
   検出した3D位置を `hand.py` の目標座標へ自動入力し、手動入力なしでマーカ位置へアームを動かす。
5. **安全範囲の実機調整**
   コメントアウト中の範囲チェックを実機に合わせて有効化。
